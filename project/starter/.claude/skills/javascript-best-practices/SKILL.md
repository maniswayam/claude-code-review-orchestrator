# JavaScript Best Practices

Use this skill when reviewing JavaScript or TypeScript files.

## Key ideas

- Prefer explicit validation and fail-fast checks.
- Avoid mutation of shared objects in hot paths.
- Use clear names and consistent error handling.
- Keep functions small and single-purpose.

## Output

Return concise findings with severity, file, and fix guidance.
